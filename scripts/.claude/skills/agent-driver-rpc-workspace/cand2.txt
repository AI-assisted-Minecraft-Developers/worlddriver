Call the agent-driver Minecraft mod's live control API over its JSON-RPC websocket (port 39801) with the bundled rpc.py client, and look up exact method params in its complete 45-method reference. Use this skill whenever you need to DRIVE or QUERY a running agent-driver client/bot — calling mc.bot.* (goto, setting, mine, build, status, cancel), mc.action.* (runCommand, fill, placeMany), mc.observe.*, mc.client.* (input, screenshot, screen, chat), mc.query, mc.wait.*, or mc.script.eval. Reach for it ESPECIALLY when the mcp__agent-driver__* tools can't do the job: a setting or param won't apply / gets stripped after you rebuilt the mod (the harness freezes MCP tool schemas at session start, so newly-added keys must be set over RPC instead), you want to send a raw method+params straight to the websocket, you need to script a multi-step live setup (give→tp→fill→setting→goto) in one shell block, or you're bringing the client up headless (title→world, input, screenshots). Also use it to answer "what RPC methods exist / how do I call X" for this mod. This is for INVOKING the mod at runtime — not for editing the mod's Java (BotConfig/ToolCatalog/Walker), writing gametests, or standing up your own MCP server, which are ordinary code tasks. If a task means controlling the live bot/client or bypassing a stale MCP tool, consult this skill rather than guessing the wire format.
